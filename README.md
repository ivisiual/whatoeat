# 饭饭搭子（whatoeat）

> 替选择困难的你，认真想好今天三顿饭

纯前端中文单页：按场景、目标、用餐方式等条件，为你安排今天的早/午/晚三餐。无后端、无构建，可双击打开或部署到 GitHub Pages。

## 功能

- **场景**（在公司 / 在家 / 加班 / 刚运动完）与 **饮食目标**（随心吃 / 吃轻一点 / 高蛋白 / 蛋奶素）可同时选择
- **用餐方式**：食堂、外卖、便利店、自己做、都可以（渠道互斥标注，结果展示不同）
- 胃口、口味、预算；忌口折叠；自制厨具/做饭时间；外卖等待时间
- 每次点击主按钮 **重新生成** 新菜单；刷新只恢复 **当天** 缓存，不写历史
- 三餐揭晓动画；单道「换一道」/ 全部换一组；餐内 **禁止同一道菜重复**
- **今日能量 · 吃饭打卡**：推荐与实际摄入分开；单餐「吃了这顿」+「补记食物」
- 可选每日热量目标与进度；摄入记录按日存储（localStorage）
- 已打卡餐次重新安排时自动锁定；推荐历史独立
- 自制菜谱优先链接 [HowToCook](https://github.com/Anduin2017/HowToCook) 真实页面

## 筛选逻辑简述

| 类型 | 条件 |
| --- | --- |
| 硬条件（不自动放宽） | 忌口/过敏、蛋奶素白名单、明确用餐方式、厨具、预算上限 |
| 软偏好（可逐步放宽） | 场景、胃口、口味、等待/做饭时间、随心吃/高蛋白等目标 |

蛋奶素仅推荐 `goals` 含 `ovo_lacto` 且 `dietFlags.ovoLactoSuitable === true` 的菜；套餐/拼盘/综合等成分不确定菜默认排除。

## 本地使用

用浏览器直接打开 `index.html` 即可。

## 部署到 GitHub Pages

1. 将本目录推送到仓库（例如 `whatoeat`）。
2. **Settings → Pages**：Source 选 branch，目录 `/ (root)`。
3. 访问：`https://<用户名>.github.io/<仓库名>/`

全相对路径，子路径部署可用。

## 技术说明

| 项 | 说明 |
| --- | --- |
| 技术栈 | 单文件 `index.html`（内联 CSS / JS） |
| 布局 | 上筛选、下三餐；断点约 1023 / 767；手机吸底主按钮 |
| 存储 | localStorage：设置、当日菜单、推荐历史、热量记录/目标、收藏 |
| 数据 | 内置 `DISHES`（`calories`/`dietFlags`）+ 50+ 常见食物估算 |
| 免责 | 热量为估算范围，不构成营养或医疗建议 |

## 自查清单

- [x] 主按钮每次生成新菜单；刷新恢复当天结果且不重复写历史
- [x] 跨日缓存不会当作「今日菜单」恢复
- [x] 蛋奶素白名单，不推荐关东煮/麻辣烫等不确定菜
- [x] 同组三餐菜品 ID 不重复；候选不足时有提示
- [x] 「今天就吃这套」同日同签名不重复记录
- [x] 桌面条件区（厨具/等待）无选渠道时隐藏，不留空白格
- [x] 320–1920 视口无横向滚动；手机吸底按钮与 safe-area
