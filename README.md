# 饭饭搭子

> 替选择困难的你，认真想好今天三顿饭

纯前端中文单页小工具：根据模式与筛选，为你安排今天的早餐、午餐、晚餐。无后端、无构建，可直接双击打开，也可部署到 GitHub Pages。

## 功能

- **上班续命 / 轻盈减脂** 两种模式
- 筛选：外卖食堂 / 自己做、耗时、不辣、不吃牛/猪肉、素食
- 日期 + 模式 + 筛选 → **每日固定推荐**（刷新不变，主动换菜才变）
- 三餐揭晓动画；单道「换一道」/ 全部换一组
- 收藏今天、复制菜单、最近 7 天历史（localStorage）
- 自制菜谱链接至 [HowToCook](https://github.com/Anduin2017/HowToCook) 真实页面

## 本地使用

用浏览器直接打开 `index.html` 即可。

## 部署到 GitHub Pages

1. 新建仓库（例如 `fanfan-dazi`），把本目录文件推上去。
2. 仓库 **Settings → Pages**：
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`（或 `master`），目录选 `/ (root)`
3. 保存后等待一两分钟，访问：

   `https://<你的用户名>.github.io/fanfan-dazi/`

本页只使用相对路径，**仓库子路径下可正常运行**。

## 技术说明

| 项 | 说明 |
| --- | --- |
| 技术栈 | 单文件 `index.html`（内联 CSS / JS） |
| 存储 | `localStorage`（设置、收藏、历史、当日计划） |
| 数据 | 内置 `DISHES` 数组，字段有注释，便于拆成 JSON |
| 免责 | 热量为估算范围，不构成营养或医疗建议 |
