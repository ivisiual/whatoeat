# 饭饭搭子（whatoeat）

> 替选择困难的你，认真想好今天三顿饭

纯前端中文单页：按「今天怎么过」快捷方案与三餐独立设置，为你安排今天的早/午/晚三餐。无后端、无构建，可双击打开或部署到 GitHub Pages。

## 功能

- **一键快捷方案**（工作日通勤、加班续命、控卡、健身、居家、懒得动、周末探索）
- **三餐独立设置**：渠道、预算、时间、胃口、餐型、当餐目标互不捆绑
- **地方菜系**（粤/赣/湘/川等）：多选为 OR，默认软偏好，可选「只看所选菜系」
- 场景、饮食目标、口味、忌口（硬条件不自动放宽）
- 每次点击主按钮 **重新生成** 新菜单；刷新只恢复 **当天** 缓存
- 三餐揭晓动画；单道「换一道」/ 全部换一组；餐内 **禁止同一道菜重复**
- **今日能量 · 吃饭打卡**：推荐与实际摄入分开；「今天就吃这套」一键写入预计热量（幂等）
- 可选每日热量目标与进度；摄入记录按日存储（localStorage）
- 自制菜谱优先链接 [HowToCook](https://github.com/Anduin2017/HowToCook)；无菜谱的探索菜只提供搜索词，不造假链接

## 筛选逻辑简述

| 类型 | 条件 |
| --- | --- |
| 硬条件（不自动放宽） | 忌口/过敏、蛋奶素白名单、唯一渠道、厨具、预算硬上限、严格菜系 |
| 软偏好（可逐步放宽） | 场景、胃口、口味、等待/做饭时间、餐型、当餐目标、菜系（软模式）、探索度 |

## 本地使用

用浏览器直接打开 `index.html` 即可（核心功能不依赖本地服务器）。

```text
whatoeat/
├─ index.html
├─ .nojekyll
├─ data/
│  ├─ cuisine-data.js    # 地方菜系种子
│  └─ dishes-data.js     # 内置菜品库
├─ docs/
│  ├─ DATA_SOURCES.md
│  └─ FILTER_AND_PRESET_V2.md
└─ README.md
```

## 部署到 GitHub Pages

1. 将本目录推送到仓库（例如 `whatoeat`）。
2. **Settings → Pages**：Source 选 branch，目录 `/ (root)`。
3. 访问：`https://<用户名>.github.io/<仓库名>/`

资源全部使用相对路径（`./data/...`），子路径部署可用。根目录保留 `.nojekyll`。

## 技术说明

| 项 | 说明 |
| --- | --- |
| 技术栈 | 静态 HTML + 内联 CSS / JS + `data/*.js` 种子 |
| 布局 | 快捷方案 + 三餐细调 + 折叠详细条件；断点约 1023 / 767 / 640 |
| 存储 | localStorage：设置 v3、当日菜单、推荐历史、吃过、热量、收藏 |
| 兼容 | 旧版 `fanfan_settings_v2`（全局 channel）自动迁移为三餐结构 |
| 免责 | 热量为估算范围，不构成营养或医疗建议 |

## 自查清单

- [x] 三餐渠道独立，工作日通勤不会三餐全外卖
- [x] 快捷方案只填默认值，仍可细调
- [x] 菜系多选 OR；严格模式候选不足时提示放宽
- [x] discovery 菜不显示虚假 GitHub 菜谱
- [x] 同组三餐菜品 ID 不重复；连续换组尽量不同
- [x] 「今天就吃这套」同菜单幂等，不重复写入
- [x] 跨日缓存不会当作「今日菜单」恢复
- [x] 320–1440 视口无横向滚动；手机吸底按钮与 safe-area
